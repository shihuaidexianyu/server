# 情况介绍

实验室当前有两台服务器，硬件配置一致，系统均为 Ubuntu 22.04.5 Desktop AMD64。本文用于说明服务器的基本情况、适合承担的任务，以及新用户开始使用前应该先阅读哪些文档。

!!! tip "复制命令说明"

    本 Wiki 中所有带有尖括号的命令，例如 `ssh <server_alias>`、`sudo ./userkit show <username>`，在复制到终端执行前，都需要将 `<server_alias>`、`<username>` 连同尖括号一起替换为实际值，例如 `server-a` 或 `alice`。

## 适合的任务

这类服务器适合：

- 脑影像和神经科学数据处理。
- AFNI、FSL、FreeSurfer 等软件批处理。
- Python、R、MATLAB 或命令行数据分析。
- 中等规模机器学习实验。
- 大容量数据暂存和共享。
- 需要长时间运行的批处理任务。

不建议直接用于：

- 未经隔离的公开 Web 服务。
- 高风险外网服务。
- 无限制占满 CPU、内存或磁盘的任务。
- 未经确认的大规模下载和爬取。

## 使用规范

- 不要在系统盘长期存放大数据。
- 大数据优先放在 `/data` 下。
- 长时间任务建议放在 `tmux` 中运行。
- 不要共享个人 SSH 私钥。
- 不要把 token、密码和密钥写入共享目录。
- 安装个人软件时优先使用 Conda 或用户目录。
- 遇到 OOM、磁盘写满、网络异常时及时记录命令和现象。
