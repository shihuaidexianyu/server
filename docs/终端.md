# 终端

终端是连接服务器、运行命令、使用 Codex 或其它 CLI 工具的主要入口。macOS 自带终端在某些 Codex 场景下可能存在兼容性问题，例如粘贴图片、复杂输入或显示行为不稳定。当前推荐使用 WezTerm 作为替代终端。

## 推荐终端

### macOS

推荐使用 WezTerm：

- 对现代终端能力支持较好。
- 跨平台配置方式统一。
- 对 SSH、长时间会话和复杂输出支持较稳定。

安装方式可以使用 Homebrew：

```bash
brew install --cask wezterm
```

如果没有安装 Homebrew，也可以从 WezTerm 官网下载图形安装包。

### Windows

推荐使用以下方案之一：

- Windows Terminal + PowerShell。
- Windows Terminal + WSL。
- MobaXterm。
- VS Code Remote SSH。

如果主要工作在服务器上，WSL 或 VS Code Remote SSH 通常比传统 `cmd.exe` 更方便。

MobaXterm 适合不想先配置 WSL 的 Windows 用户。它集成 SSH、SFTP 文件浏览器、X11 转发和常用 Unix 命令，官方下载地址：

```text
https://mobaxterm.mobatek.net/download.html
```

MobaXterm 连接服务器的基本步骤：

1. 打开 MobaXterm。
2. 点击 `Session`。
3. 选择 `SSH`。
4. `Remote host` 填服务器管理 IP 或主机名，例如 `server-a`。
5. 勾选 `Specify username`，填自己的 `<username>`。
6. `Port` 保持 `22`。
7. 如果使用私钥，在 `Advanced SSH settings` 中选择私钥文件。
8. 保存后双击会话连接。

MobaXterm 登录成功后，左侧通常会出现 SFTP 文件面板。小文件可以通过该面板上传下载；大数据传输仍建议使用 [大容量存储](大容量存储.md) 中的 `rsync`。

### Linux

大多数现代终端都可以使用，例如 GNOME Terminal、Konsole、Alacritty、WezTerm 等。

## SSH 登录

终端中最常见的操作是 SSH 登录服务器：

```bash
ssh <server_alias>
```

服务器别名来自本机 `~/.ssh/config` 配置。具体配置方式参见 [ssh登录.md](ssh登录.md)。

## 长时间任务建议

训练模型、下载数据、批处理影像、AI agent 等任务可能运行很久，不建议直接裸跑在普通 SSH 会话中。推荐使用 `tmux`。

新建会话：

```bash
tmux new -s <session_name>
```

示例：

```bash
tmux new -s freesurfer
tmux new -s ai
```

在 tmux 中正常运行你的命令。需要临时断开但保留任务时，按：

```text
Ctrl-b 然后按 d
```

这叫 detach，会返回普通 shell，但 tmux 会话里的任务继续运行。

查看已有会话：

```bash
tmux ls
```

重新进入会话：

```bash
tmux attach -t <session_name>
```

如果只有一个会话，也可以：

```bash
tmux attach
```

重命名当前会话：

```bash
tmux rename-session -t <old_session_name> <new_session_name>
```

关闭某个会话：

```bash
tmux kill-session -t <session_name>
```

这样即使本地网络断开，服务器上的任务也不会因为终端关闭而直接中止。

tmux 常用快捷键：

| 快捷键 | 作用 |
| --- | --- |
| `Ctrl-b d` | 断开当前会话但保留任务 |
| `Ctrl-b c` | 新建窗口 |
| `Ctrl-b n` | 切到下一个窗口 |
| `Ctrl-b p` | 切到上一个窗口 |
| `Ctrl-b "` | 上下分屏 |
| `Ctrl-b %` | 左右分屏 |
| `Ctrl-b x` | 关闭当前 pane |

## 常用检查命令

查看当前机器和用户：

```bash
hostname
whoami
pwd
```

查看系统资源：

```bash
htop
df -h
free -h
```

查看当前 shell：

```bash
echo "$SHELL"
```

服务器默认假设用户使用 Bash。部分全局命令只在 Bash 下测试过，参见 [bash继承.md](bash继承.md)。

## 终端显示异常

如果出现中文乱码、颜色异常或退格键异常，可以先检查环境变量：

```bash
echo "$LANG"
echo "$TERM"
```

常见设置如下：

```bash
export LANG=en_US.UTF-8
export LC_ALL=en_US.UTF-8
```

不建议随意把这些配置写入全局文件，除非已经确认所有用户都需要。

## 使用 Codex 或 AI CLI

如果要在终端中使用 Codex、Claude Code 等 AI CLI 工具，需要先准备 Node.js 或对应运行时，并根据网络情况开启代理。相关说明参见 [AI使用.md](AI使用.md) 和 [代理网络连接.md](代理网络连接.md)。
