# 终端

终端是连接服务器和运行命令的入口。macOS 自带 Terminal 足以完成 SSH 操作；需要统一跨平台配置时，可以选用 WezTerm。具体 CLI 的输入或显示问题应按工具版本排查，本页不把个别现象归为某个终端的普遍缺陷。

> **【说明】适用对象与完成标准**
>
> - **适用对象**：所有普通用户。
> - **前置条件**：本机能够安装或打开一个终端；SSH 登录信息参见 [15 分钟快速开始](快速开始.md)。
> - **所需权限**：本机普通用户权限；服务器上不需要 `sudo`。
> - **完成标准**：能够打开终端、通过 SSH 登录，并创建、断开和恢复一个 `tmux` 会话。

## 推荐终端

### macOS

推荐使用 WezTerm：

- 对现代终端能力支持较好。
- 跨平台配置方式统一。
- 对 SSH、长时间会话和复杂输出支持较稳定。

安装方式可以使用 Homebrew：

```bash
brew install --cask wezterm
```

如果没有安装 Homebrew，也可以从 WezTerm 官网下载图形安装包。

### Windows

推荐使用以下方案之一：

- Windows Terminal + PowerShell。
- Windows Terminal + WSL。
- MobaXterm。
- VS Code Remote SSH。

如果主要工作在服务器上，WSL 或 VS Code Remote SSH 通常比传统 `cmd.exe` 更方便。

MobaXterm 适合不想先配置 WSL 的 Windows 用户。它集成 SSH、SFTP 文件浏览器、X11 转发和常用 Unix 命令，官方下载地址：

```text
https://mobaxterm.mobatek.net/download.html
```

MobaXterm 连接服务器的基本步骤：

1. 打开 MobaXterm。
2. 点击 `Session`。
3. 选择 `SSH`。
4. `Remote host` 填管理员私下提供的服务器管理地址；`server-a` 仅是示例名称。
5. 勾选 `Specify username`，填自己的 `<username>`。
6. `Port` 保持 `22`。
7. 如果使用私钥，在 `Advanced SSH settings` 中选择私钥文件。
8. 保存后双击会话连接。

MobaXterm 登录成功后，左侧通常会出现 SFTP 文件面板。小文件可以通过该面板上传下载；大数据传输仍建议使用 [大容量存储](大容量存储.md) 中的 `rsync`。

### Linux

大多数现代终端都可以使用，例如 GNOME Terminal、Konsole、Alacritty、WezTerm 等。

## SSH 登录

终端中最常见的操作是 SSH 登录服务器：

```bash
ssh <server_alias>
```

服务器别名来自本机 `~/.ssh/config` 配置。具体配置方式参见 [SSH 登录](ssh登录.md)。

## 长时间任务建议

训练模型、下载数据、批处理影像、AI agent 等任务可能运行很久，不建议直接裸跑在普通 SSH 会话中。推荐使用 `tmux`。

新建会话：

```bash
tmux new -s <session_name>
```

示例：

```bash
tmux new -s freesurfer
tmux new -s ai
```

在 tmux 中正常运行你的命令。需要临时断开但保留任务时，按：

```text
Ctrl-b 然后按 d
```

这叫 detach，会返回普通 shell，但 tmux 会话里的任务继续运行。

查看已有会话：

```bash
tmux ls
```

重新进入会话：

```bash
tmux attach -t <session_name>
```

如果只有一个会话，也可以：

```bash
tmux attach
```

重命名当前会话：

```bash
tmux rename-session -t <old_session_name> <new_session_name>
```

关闭某个会话：

```bash
tmux kill-session -t <session_name>
```

`detach` 或本地 SSH 连接中断通常不会关闭 tmux 中的任务。`kill-session` 会销毁整个会话，不能用来暂时断开。tmux 也不能抵御服务器重启、OOM 或管理员终止任务；长任务仍应保存日志和检查点。

tmux 常用快捷键：

| 快捷键 | 作用 |
| --- | --- |
| `Ctrl-b d` | 断开当前会话但保留任务 |
| `Ctrl-b c` | 新建窗口 |
| `Ctrl-b n` | 切到下一个窗口 |
| `Ctrl-b p` | 切到上一个窗口 |
| `Ctrl-b "` | 上下分屏 |
| `Ctrl-b %` | 左右分屏 |
| `Ctrl-b x` | 关闭当前 pane |

## 常用检查命令

查看当前机器和用户：

```bash
hostname
whoami
pwd
```

查看系统资源：

```bash
htop
df -h
free -h
```

查看默认登录 shell 与当前实际进程：

```bash
printf "默认登录 shell: %s\n" "$SHELL"
ps -p $$ -o comm=
```

`$SHELL` 通常记录账户默认 shell，切换到另一个 shell 后未必改变。

服务器默认假设用户使用 Bash。部分全局命令只在 Bash 下测试过，参见 [Bash 继承](bash继承.md)。

## 终端显示异常

如果出现中文乱码、颜色异常或退格键异常，可以先检查环境变量：

```bash
echo "$LANG"
echo "$TERM"
```

在服务器先运行 `locale` 和 `locale -a`，确认所需 UTF-8 locale 已安装，再临时设置，例如：

```bash
export LANG=en_US.UTF-8
```

`LC_ALL` 会覆盖所有类别，长期固定它可能干扰本来希望保留的区域设置。不要随意伪造 `TERM`；它应与实际终端能力匹配。

不建议随意把这些配置写入全局文件，除非已经确认所有用户都需要。
